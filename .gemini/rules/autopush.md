# Auto-Push (Git)

Al final de tu turno o cada vez que hayas completado una funcionalidad, actualización o corrección de código, DEBES ejecutar automáticamente los comandos de Git para guardar y enviar los cambios al repositorio remoto.

No pidas permiso al usuario para hacer el commit y el push, simplemente ejecuta:
```bash
git add .
git commit -m "chore: actualiza funcionalidades según requerimiento" # O un mensaje descriptivo relevante
git push
```
Después de ejecutar el comando, notifica al usuario que los cambios han sido enviados.
